# کافینو | CAFINO — نسخهٔ آنلاین (v1.88.0)

سامانه مدیریت هوشمند کافی‌نت. این مخزن فقط **خروجی ساخته‌شدهٔ برنامه** (PWA) را برای GitHub Pages نگه می‌دارد؛ سورس برنامه در مخزن جدا و خصوصی است.

- بدون سرور: ثبت‌نام/ورود محلی (فقط روی همان مرورگر)، ورود مهمان، فروش، فاکتور، گزارش و کار آفلاین.
- ویژگی‌های وابسته به سرور (QR دریافت فایل، همگام‌سازی، اطلاعیه و تیکت) تا وقتی `apiBaseUrl` در `config.js` تنظیم نشود غیرفعال‌اند.

این فایل‌ها خودکار تولید می‌شوند (`node scripts/make-site.mjs`)؛ مستقیم ویرایششان نکنید.
