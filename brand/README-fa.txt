لوگوی رسمی کافینو (فایل‌های اصلی طراح):
  logo.svg / logo.png        لوگوی کامل (نشان + نوشته) برای پس‌زمینهٔ روشن
  logo-white.svg / .png      نسخهٔ سفیدِ نوشته برای پس‌زمینهٔ تیره
  logo-mono.svg              تک‌رنگ
  icon.svg / icon-192.png / icon-512.png / apple-touch-icon.png   آیکن مربعی برنامه

لوگو داخل برنامه جاسازی شده است (src/app/components/brandAssets.js، ساخته‌شده با: node scripts/gen-brand-assets.mjs).
پس از تغییر لوگو:  node scripts/gen-brand-assets.mjs && node scripts/make-brand-icons.mjs
برای جایگزینی بدون بیلد: در config.js مقدار brandLogoUrl را "brand/logo.svg" یا "brand/icon-512.png" بگذارید.
