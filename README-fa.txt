نصب نسخه PWA — کافینو | CAFINO
1) پوشه pwa را روی هر هاستی با HTTPS آپلود کنید (Netlify، Vercel، GitHub Pages، هاست سی‌پنل...). نیازی به سرور خاصی نیست.
   تست محلی: داخل پوشه  npx serve .   (روی localhost هم کار می‌کند)
2) اندروید/کروم و کامپیوتر: دکمه «نصب» داخل برنامه یا آیکن نصب در نوار آدرس.
3) آیفون: Safari ← Share ← Add to Home Screen.
نکته: داده‌ها در مرورگر همان دستگاه ذخیره می‌شوند؛ هر دستگاه داده جدا دارد. از بخش پشتیبان‌گیری استفاده کنید.
نکته: برای آپدیت، فایل‌ها را جایگزین کنید و VERSION در sw.js را تغییر دهید.

اتصال به سرور (فقط برای مدیر نصب)
- در خود برنامه هیچ گزینه‌ای برای تنظیم سرور نمایش داده نمی‌شود.
- اگر سرور دارید، فایل config.js کنار index.html را باز کنید و نشانی را بنویسید، مثلاً:
    window.CAFINO_CONFIG = { apiBaseUrl: "https://api.example.com", cafeId: "" };
- اگر خالی بماند، برنامه کاملاً محلی (بدون سرور) کار می‌کند.
